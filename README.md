# 🛡️ ZeroServer.tools — Feedback & Bug Tracker

Welcome to the official feedback repository for [ZeroServer.tools](https://zeroserver.tools). 

ZeroServer is a suite of hyper-fast, 100% private developer utilities. All processing happens locally in your browser, meaning your data never touches a server. This repository is dedicated to gathering community feedback, tracking bugs, and discussing new feature requests.

---

## 💡 How to Contribute

We want to build the exact tools you need. If you have found a bug or have an idea for a new utility, please open an issue!

### 🐛 Reporting a Bug
If something isn't working right, please [open a Bug Report](../../issues/new). 
To help us fix it quickly, please include:
1. **The Tool:** Which formatter/encoder were you using?
2. **The Issue:** What happened? (e.g., "The JSON formatter failed on this specific string...")
3. **Your Environment:** Browser (Chrome, Firefox, Safari) and OS.
4. **Screenshots:** If applicable, drop a screenshot in the issue!

### ✨ Requesting a Feature
Missing a tool? Want us to add a SQL Beautifier, a Hash Generator, or a Regex Tester? [Open a Feature Request](../../issues/new) and tell us:
1. **The Tool/Feature:** What should we build?
2. **The Use Case:** How would this help your daily workflow?

---

## 🔒 Security Notice

**DO NOT post sensitive data, actual JWTs, real API keys, or proprietary code in this public repository.** ZeroServer is built on the philosophy of absolute privacy. When reporting bugs, please use dummy data or redact any sensitive information before pasting it into a GitHub Issue.
